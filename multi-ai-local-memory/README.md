# Multi-AI Local Memory / 多 AI 本地共享記憶

**一份存在自己電腦上的記憶，讓多個 AI 一起讀、一起寫、一起更新。**

**One local memory shared across multiple AI models — read, write, update, and sync together.**

This ClawHub package contains only the OpenClaw Skill instructions. The Local Bridge, browser adapter, installer, and runtime are distributed separately from the canonical GitHub project:

https://github.com/a7904282000/multi-ai-local-memory

Public Beta release:

https://github.com/a7904282000/multi-ai-local-memory/releases/tag/v1.0.0-beta.1

## What it does

- Shared local memory across supported AI models and agents.
- Obsidian by default; replaceable storage adapters.
- OpenClaw by default as intermediary; not required.
- Automatic recall/capture/sync when the connected surface supports the required hooks.
- Existing imported source memories are preserved byte-for-byte.
- Not every chat becomes long-term memory.
